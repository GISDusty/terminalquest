# Hello, TerminalQuest!

Write your first Rust program. Create a file called `main.rs` anywhere on your
computer, and make it print one line of text.

<div class="aside">
<h3>Requirements</h3>
<ul>
  <li>Install Rust with <code>rustup</code> (<code>https://rustup.rs</code>). Check it with <code>rustc --version</code> in a terminal.</li>
  <li>Create a file that ends in <code>.rs</code>, for example <code>main.rs</code>.</li>
  <li>Write a <code>main</code> function that prints <code>Hello, TerminalQuest!</code> followed by a new line.</li>
  <li>Paste the full path to the file into the first box and press HACK.</li>
</ul>
</div>

The terminal compiles your file with `rustc` into a temporary folder, runs the
result for up to five seconds, and reads what it prints. It does not change
your file.
